BrideApp Overview

This is a final year project aiming to bridge the connection between empowered women showcasing their skills and customers that are looking for that particular skill.

The code you can access through the folders above.

React frontend, postgres backend, connected with Node.js and express.

You can analyze the structure of the database using the schemas in the database folder.

Current goals:
- Complete the website version to include a better designed homepage
- A category page that the user lands on after logging in (wireframe will be provided)
- A "just browsing as a guest" feature
- A mobile screen with flutter
